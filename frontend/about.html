How PinAI Works With Unsplash API

PinAI provides a modern Pinterest-style interface powered entirely by the official Unsplash REST API. Every photograph, category, and search query flows dynamically through a secure Node.js proxy layer with zero local image storage.

🔄 5-Step Data Flow Architecture

How image requests travel from your browser to Unsplash's cloud and back in milliseconds.

1

User Action

The user loads the Feed, scrolls for infinite pagination, or enters a keyword like "minimalist architecture" into the search bar.

2

Browser → Node Proxy

The browser executes a lightweight native fetch() request to the local backend proxy at /api/photos or /api/search.

3

Security & Caching

Express checks its in-memory TTL cache (5-min lifetime). If uncached, it attaches the private Authorization: Client-ID key and calls api.unsplash.com.

4

JSON Payload Return

Unsplash returns photo metadata (dimensions, BlurHash, CDN URLs, creator profile links). The proxy strips bloat and returns a clean JSON payload.

5

Hotlinking & Render

Frontend dynamically builds the Pinterest masonry grid. Photos are loaded directly from images.unsplash.com without consuming local disk space.

GET /api/search?q=:query&page=:n
→ https://api.unsplash.com/search/photos

Executes keyword search through Unsplash's neural visual search and community tag index. Includes live 400ms debounce to minimize unnecessary network calls.

GET /api/topics
→ https://api.unsplash.com/topics

Retrieves featured editorial topics (e.g. Wallpapers, 3D Renders, Nature, Architecture) to dynamically populate the Feed page category chips bar.

GET /api/photos/:id/download
→ https://api.unsplash.com/photos/:id/download

Mandatory Unsplash Guideline: Whenever a user clicks "Download", this endpoint is invoked to report a download event to Unsplash, incrementing the photographer's verified metrics and returning a high-res direct download link.

🛡️ Unsplash API Guidelines & Developer Rules

How PinAI rigorously satisfies every item in the Unsplash Developer Production Checklist:

🔗

1. Hotlink Images Directly

Unsplash requires image URLs to be embedded directly into <img src> without storing them on your own servers. This ensures proper CDN caching and view metric attribution for creators.

👤

2. Creator Attribution

Every pin card and detail modal explicitly displays the photographer's full name, avatar, and referral link back to their Unsplash profile with proper UTM parameters (utm_source=pinai).

📥

3. Trigger Download Events

When users download an image, PinAI notifies photo.links.download_location through our proxy to accurately track community popularity.

🔐

4. Private API Key Security

The UNSPLASH_KEY is stored strictly in server-side .env. Frontend JavaScript only communicates with /api/* and never has access to secret tokens.

⏱️

5. Rate Limiting & Caching

Demo applications are restricted to 50 requests/hour. PinAI uses an in-memory 5-minute TTL cache (capped at 100 entries) to prevent redundant queries and avoid 429 rate limit errors.

🎨

6. Distinct Visual Identity

PinAI does not clone Unsplash's trademark or logo. It uses an original Apple OS inspired dark glassmorphic design and Pinterest masonry grid layout.
